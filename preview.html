❗ Hard requirement: NO big memory needed
The box has only 38 GB of RAM (plain home DDR, no ECC, not a server, no pinned host memory). The 169 GB model (incl. ~102 GB PLE table) barely touches RAM — served via NVMe mmap demand-paging, steady ≈11 GiB, load peak ~20 GiB.
Community contrast: 47.7 GB pinned sidecar + 96 GB RAM → this reproduces on 1/3 the memory, on a home PC.
⚠️ 硬性要求：模型盘 read-ahead 必须调到 16 KiB
sudo blockdev --setra 32 /dev/nvme0n1（32×512B=16 KiB，内核默认 128 KiB；实测值 getra=32）。 PLE mmap 是小随机读，默认 128 KiB 预读会 ~8× 放大打爆 NVMe 队列，prefill / decode 与同盘正常读取全都跑不动。 重启会掉回默认值，需 udev 持久化（ATTR{bdi/read_ahead_kb}="16"）。无论我方还是社区文档都没提这个参数——数字难看先查它。
